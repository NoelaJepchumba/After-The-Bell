
# AFTER THE BELL - Product Overview

## Project Description
AFTER THE BELL is a browser-based, first-person 3D supernatural horror game set in a mysterious classroom.

## Core Gameplay
- The player investigates eight classmates.
- Each classmate has a secret supernatural identity.
- Players observe behaviour, collect clues and make accusations.
- Players must survive until the final bell.
- Incorrect accusations have serious consequences.

## Supernatural Identities
- Vampire
- Werewolf
- Ghost
- Witch
- Shapeshifter
- Demon
- Zombie
- Siren

## Main Features
- First-person 3D classroom exploration.
- Interactive classmates with different behaviours.
- Investigation notebook and clue collection.
- Student accusation system.
- Supernatural classroom events.
- Five-minute and twenty-minute game modes.
- Game timer, composure system and survival conditions.

## Technology Stack
- React
- Vite
- JavaScript
- Three.js
- React Three Fiber
- CSS

## Design Direction
The game should have a dark, atmospheric supernatural horror aesthetic.
The classroom should initially appear ordinary before gradually becoming disturbing.

## Development Guidelines
- Preserve the existing project architecture.
- Avoid unnecessary dependencies.
- Keep game systems modular.
- Maintain existing functionality when adding features.
- Test changes before considering them complete.
